# Lua 5.3.4 Test Suite

`lua-5.3.4-tests/` is the official Lua 5.3.4 test suite from https://www.lua.org/tests/.
The original archive is retained as `lua-5.3.4-tests.tar.gz` for provenance.
These third-party files are kept in their original formatting.

LuaAE runs the portable selection with `_port=true`; see the ignored release
test in `tests/vm_stack.rs` for the exact command and success checks.
